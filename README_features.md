# 象棋引擎日志显示功能

## 功能概述

本项目已经成功实现了将服务端每一步行棋的打印信息发送给客户端，并在网页上用对话框展示的功能。

## 主要改进

### 1. 服务端改进 (ui-server.py)

- **日志收集机制**: 添加了日志收集功能，捕获elephantfish引擎的所有打印输出
- **结构化日志**: 将日志信息组织成结构化的数组，包含以下信息：
  - 玩家输入移动
  - 当前棋盘状态
  - AI思考过程（搜索深度、评分、用时）
  - AI最终移动
  - 移动后棋盘状态

### 2. 前端改进

#### HTML (ui/chess.html)
- 添加了日志对话框组件
- 包含标题栏和关闭按钮
- 可滚动的内容区域

#### CSS (ui/styles.css)
- 设计了美观的对话框样式
- 响应式布局
- 良好的用户体验

#### JavaScript (ui/script.js)
- 添加了显示/隐藏日志对话框的功能
- 在接收到服务端响应时自动显示日志
- 支持关闭对话框

## 使用方法

### 启动服务

1. 启动服务端：
```bash
python ui-server.py
```

2. 启动前端服务器：
```bash
cd ui
python -m http.server 8081
```

3. 访问网页：
```
http://localhost:8081/chess.html
```

### 测试功能

也可以使用测试页面：
```
http://localhost:8081/test.html
```

## 功能特点

1. **实时日志显示**: 每次移动后都会显示AI的思考过程
2. **详细信息**: 包括搜索深度、评分、用时等详细信息
3. **棋盘状态**: 显示移动前后的棋盘状态
4. **用户友好**: 美观的对话框界面，易于阅读
5. **可关闭**: 用户可以随时关闭日志对话框

## 技术实现

### 服务端技术
- Python HTTP服务器
- 输出重定向捕获
- JSON数据格式

### 前端技术
- 原生JavaScript
- CSS3样式
- HTML5结构
